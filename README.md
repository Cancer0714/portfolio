<h1>アプリの使い方</h1>
ボタンをクリックすると、そのボタンに書かれているコード音が鳴ります。
<br>クリックしたコードは、画面下にあるコード進行欄に記憶され、連続して再生することができます。
<br>コードボタンと、再生ボタンのクリックのみで、簡単にコードを作ることができます。
<br>良いコードが作れない場合は、チャットポットに相談することもできます。

<h1>機能一覧</h1>
<br>・C、F、Gメジャー/マイナーのダイアトニックコードをワンクリックで鳴らせる
<br>・チャットポットを使って、自分が作りたいコード進行を簡単に作成
<br>・気に入ったコード進行を再生/保存し、いつでも参照できる
