<h1>アプリ概要</h1>
<br>ワンクリック操作で、和音を簡単に組み立てられるアプリ

<h1>使用技術</h1>
Next.js、supabase、Tone.js
<h1>機能一覧</h1>
<br>・C、F、Gメジャー/マイナーのダイアトニックコードをワンクリックで鳴らす
<br>・任意のコードを選択し、コード進行として組み立てる
<br>・組み立てたコード進行を再生
<br>・気に入ったコード進行を保存し、いつでも再生できる
