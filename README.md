<h1>使用技術</h1>
<h1>機能一覧</h1>
・C、F、Gメジャー/マイナーのダイアトニックコードをワンクリックで鳴らす
・任意のコードを選択し、コード進行として組み立てる
・組み立てたコード進行を再生
・気に入ったコード進行を保存し、いつでも再生できる
